## Critical directories (game profile)

| Path | Role |
|------|------|
| `Assets/Scripts` | All first-party gameplay and integration glue |
| `Assets/Scenes` | Editor-build scenes; entry order in `EditorBuildSettings.asset` |
| `Assets/Resources` | `Resources.Load` and addressable-style organization for art/UI |
| `Packages/manifest.json` | Declares Unity packages (2D, Ads, Services, uGUI, tests, IDE) |
| `ProjectSettings` | Editor version, platform, build scene list |

## Entry points

- **Player entry (build):** `Assets/Scenes/Intro.unity` → `Assets/Scenes/MainScene.unity` (both enabled in `EditorBuildSettings.asset`).  
- **Code entry:** No single `Program.cs`; Unity uses **scene hierarchy** and **MonoBehaviour** scripts attached to objects. Likely coordinators include `SplashManager`, `TitleScreen`, `SceneManager` (see `Assets/Scripts/Scene/SceneManager.cs`) — confirm in Editor which objects reference them.

## Integration / vendor code

- **`Assets/Extensions/GooglePlayGames`** — Play Games Services plugin code.  
- **`Assets/Extensions/CloudOnce`** — Cloud save / achievements abstraction.  
- **`Assets/ExternalDependencyManager`** — Dependency resolution for mobile SDKs.

## Excluded / generated (standard Unity)

- `Library/`, `Temp/`, `obj/`, `Builds/` — ignored per `.gitignore`; not in version control.  
- `*.csproj` / `*.sln` — ignored; regenerated by Unity/IDE.

## Multi-part / monorepo

**None.** Single Unity project; no separate server or web client in this repo.
